# Product 3D Models Directory

Place your custom `.glb` or `.gltf` 3D product models here.

Example:
`public/models/product.glb`

When `product.glb` is present, `ProductModel.tsx` will automatically detect and load it, recoloring its materials seamlessly.
If no `.glb` file is placed here, Proto3D automatically falls back to its procedural high-fidelity 3D headset model.
